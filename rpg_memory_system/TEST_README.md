# 记忆系统功能测试指南

本测试套件用于验证新修改的记忆系统功能，包括定时处理机制、核心记忆修复和LangSmith监控集成。

## 🎯 测试目标

1. **定时处理机制测试** - 验证用户离线1小时后自动处理记忆的功能
2. **核心记忆修复测试** - 验证核心记忆能正常导入和更新
3. **LangSmith监控测试** - 验证大模型调用的完整监控和记忆组装过程
4. **完整提示词打印** - 在后端日志中查看每轮对话组装的完整提示词内容

## 🚀 快速开始

### 1. 环境准备

确保 `.env` 文件包含以下配置：

```env
# LLM配置
OPENAI_API_KEY=your_api_key_here
OPENAI_BASE_URL=your_base_url_here
OPENAI_MODEL=your_model_name
EMB_MODEL=your_embedding_model

# 数据库配置
DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/dbname
REDIS_URL=redis://localhost:6379/0

# LangSmith配置（已在测试中自动配置）
LANGSMITH_API_KEY=<your_langsmith_api_key>
```

### 2. 运行测试

```bash
# 方法1: 使用运行脚本（推荐）
python run_test.py

# 方法2: 直接运行测试文件
python test_memory_features.py
```

## 📊 测试内容详解

### 测试1: 初始化用户记忆
- 创建测试用户的记忆空间
- 验证初始化流程是否正常

### 测试2: 对话添加和记忆处理
- 添加多轮对话（达到60轮触发阈值）
- 验证记忆处理是否自动触发
- 检查记忆提取和存储流程

### 测试3: 记忆上下文获取和LangSmith监控
- 测试多个查询的记忆检索
- **完整提示词打印** - 在日志中显示发送给LLM的完整内容
- **LangSmith监控** - 追踪LLM调用和记忆组装过程
- 验证核心记忆和长期记忆的正确组装

### 测试4: 定时器功能
- 验证定时器服务是否正常运行
- 测试用户活动时间更新
- 检查定时器状态监控

### 测试5: 核心记忆修复
- 验证核心记忆能正常从Redis缓存获取
- 检查记忆处理后的缓存更新
- 确认核心记忆修复是否生效

### 故障排查

❌ **导入错误**
```

```

❌ **环境变量缺失**
```
解决方案：检查 .env 文件，确保所有必要的配置项都已设置

```
解决方案：确保PostgreSQL和Redis服务正在运行，检查连接字符串
